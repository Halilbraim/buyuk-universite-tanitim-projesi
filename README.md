# 📝 Not Uygulaması

Kullanıcıların günlük notlarını, ders içeriklerini ve görevlerini kolayca organize etmelerini sağlayan modern ve kullanışlı bir masaüstü/web not alma uygulaması.

---

## 🚀 Özellikler

- ✏️ **Hızlı Not Oluşturma:** Anlık düşüncelerinizi, ders notlarınızı veya yapılacaklar listenizi kolayca kaydedin.
- 🗂️ **Kategorizasyon:** Notlarınızı konularına veya derslerinize göre gruplayın.
- 💾 **Yerel Veri Depolama:** Verileriniz güvenli bir şekilde bilgisayarınızda yerel olarak saklanır.
- 🔍 **Arama ve Filtreleme:** Kaydedilen notlar arasında hızlıca arama yapın.
- 🎨 **Sade ve Modern Arayüz:** Göz yormayan, odaklanmayı artıran minimalist tasarım.

---

## 🛠️ Teknolojiler

Bu projede kullanılan ana teknolojiler:

- **Frontend:** HTML5, CSS3, JavaScript
- **Masaüstü Ortamı:** Electron / Node.js
- **Sürüm Kontrolü:** Git & GitHub
